Docker est une plateforme de **conteneurisation** qui permet d'empaqueter une application avec toutes ses dépendances dans un conteneur isolé.

  <img src="https://www.docker.com/wp-content/uploads/2022/03/Moby-logo.png" alt="Docker Logo" width="200"/>
</p>

## En termes simples

Imaginez Docker comme une **boîte standardisée** pour votre application. Cette boîte contient :
- Votre code
- Les bibliothèques nécessaires
- Les outils système
- Tout ce dont l'application a besoin pour fonctionner

## Avantages principaux

**Portabilité** : "Ça marche sur ma machine" → "Ça marche partout"
- Votre conteneur fonctionne de la même façon sur votre PC, sur un serveur ou dans le cloud

**Isolation** : Chaque conteneur est indépendant
- Pas de conflits entre applications
- Environnements séparés

**Légèreté** : Plus rapide qu'une machine virtuelle
- Démarre en quelques secondes
- Utilise moins de ressources

**Reproductibilité** : Même environnement à chaque fois
- Facilite le travail en équipe
- Simplifie les déploiements

## Exemple concret

Au lieu d'installer manuellement Python, PostgreSQL, Redis et toutes les dépendances sur chaque serveur, vous créez un conteneur Docker qui contient tout ça, et vous le déployez n'importe où en une commande.

C'est devenu un standard dans le développement moderne et le DevOps !
